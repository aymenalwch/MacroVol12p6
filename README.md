# MacroVol 12+6pots
A macropad with 12 keys and 6 potentiometers for volume control, powered by an RP2040 and Arduino Nano.

# Features
The 3D printable case can be found in the case folder. 

MacroVol uses the QMK firmware.
See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools)
and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information.
Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

    make handwired/aymen3dev/macrovol2p6:vial
