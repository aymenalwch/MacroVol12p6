# Svoly 12+4pots
A macropad with 12 keys and 4 pottensiometer for volume control powered by an RP2040.

# Features
The 3D printable case can be founded in the case folder. 

Svoly uses the QMK firmware.
See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools)
and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information.
Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

    make slily/svoly12n4:default
